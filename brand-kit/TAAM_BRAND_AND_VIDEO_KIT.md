## 2. Voice

**Bold, confident, strategic, modern, relentless.** We sound like a team that has already solved this problem for other businesses and knows exactly how to solve it for you.

- **Direct.** Say what we do and what it gets the client. Cut the filler.
- **Recommend, don't suggest.** "Here's what we'd do," not "you might consider."
- **Confident, not arrogant.** Back claims with results, not swagger.
- **Clear over clever.** Bold never means vague. No jargon.
- **Outcome first.** Talk about calls, bookings, leads and being found, not deliverables.
- **Short.** Short sentences, short lines. One idea per slide, poster or section.

**Phrases we use:** "Making the best brands better" · "One team, every channel" · "Built to perform" · Found / Called / Booked

**Words we never use**
- Agency filler: synergy, turnkey solutions, leverage, cutting-edge, best-in-class, solutions provider.
- Hedging: maybe, might, hopefully, we'll try, sort of.
- Anything that reads like a template.

**Example**
- ✗ "We offer turnkey digital solutions that may help you leverage your online presence."
- ✓ "Your site should ring your phone. We build the site, the content and the search that make it ring."

## 3. Pricing rule (never break)

- TAAM **never** gives discounts. Never write "discount", "% off", "deal", "save", "sale", "sale price", or show crossed-out prices.
- A smaller budget gets a **smaller scope at the same rates**, never a lower price.
- Bonuses are things we **add**, not money off.

## 5. Type

- **Montserrat only.** Headlines Montserrat Bold to Black (800–900), **ALL CAPS**, tight line height. Body Montserrat Regular, sentence case.
- **Outline type for statements:** a headline line set as an outline (white or orange stroke, no fill), paired with a solid line above or below it.
- **The orange marker:** one key word sits solid on an orange highlight block.
- Headlines are big. If a headline needs more than two lines, cut words.
- At most 3–4 short lines of body copy per poster, slide or card.

## 6. Imagery (strict)

**Only the TAAM character style.** Everywhere: slides, website, posters, social, docs.

- **The mascot:** the black-and-white rubber-hose cartoon character. Poses: `wave`, `peek`, `chill` (pointing), `phone`, `famous` (trophy), `counting`, `money-gun`, `sitting` (coin flip), `fishing`.
- **Props** drawn in the same style: bold black outlines, flat black and white, no shading. Existing props: phone-ringing, map-pin, search-bar, megaphone, stars, browser, growth, calendar, clapper, notify, coffee-cup, burst (starburst badge).
- **Supporting graphics:** the TAAM A-mark, halftone dot screen, doodle arrows, die-cut sticker treatment, big rounded image cards.

**Never**
- No photos, stock images, cinematic or 3D AI imagery.
- **No AI-generated humans of any kind:** no people, faces, bodies, hands, crowds or silhouettes.
- No other illustration styles (no flat-vector corporate people, no gradients, no clip art).

**Making new art:** generate with Codex (or any image tool) using the existing mascot PNGs as the reference. Every prompt ends with:

> flat black-and-white rubber-hose cartoon style, bold black outlines, no shading, white background, no people, no hands, no faces, no silhouettes

Check every output before using it. Reject anything with a person, face, hand or silhouette in it.

## 7. Layout direction

- **One idea per piece.** A big headline, at most 3–4 short lines, one CTA.
- **Editorial / sales look:** huge all-caps headline, lots of space, strong blocks of orange and ink.
- **Rounded cards:** images and tips sit on big rounded white cards.
- **Tilted bands and tickers** for energy: a marquee strip alternating solid and outline words.
- **Mascot as the guide:** it points at the key line, peeks over a card, or holds the prop that matches the message.
- Cut anything a reader would skim past.

**Format starters**
- **Poster / flyer:** orange or ink ground → outline + solid headline → one mascot pose → one line → CTA pill + taambetter.com.
- **Social post:** one word or number punch on the orange marker, mascot or prop, logo bottom corner.
- **Doc / proposal:** white pages, ink body text, orange section rules and headings in caps, one orange-or-ink cover page with the mascot.
- **Slide:** one idea, big headline, orange/ink alternating slide to slide.

# PART 2: Video editing kit

_The kit lives in `taam-video-kit/` inside this folder. Asset paths below are relative to `taam-video-kit/`._


Reusable motion graphics in the TAAM website style: Montserrat 900 all-caps, orange `#F46325` / ink `#111111`, white type, outline type for statements, the halftone dot screen and the black-and-white rubber-hose mascot. The brand is carried by more than the mascot: a set of props drawn in the same bold-outline style, the A-mark, outline type, the orange marker and the halftone screen. `index.html` is a 39 s demo reel that uses every block.

```bash
npm run dev      # preview and edit in the browser
npm run check    # lint, layout and motion checks
npm run render   # render index.html to MP4
```

## Making new art with Codex

`art-src/gen.sh` asks Codex for one prop in the house style, using existing TAAM art as the line-weight reference. `art-src/cutout.py` removes the white background and saves a trimmed webp.

```bash
cd art-src
./gen.sh trophy "a chunky trophy cup with two handles and sparkle marks"
python cutout.py props/trophy.png ../assets/props/trophy.webp
```

Then add the name to the `pose` lists in the blocks that should offer it. Look at every image before using it: no people, faces, hands or silhouettes.

## Using a block

Mount it in `index.html` with a host `div`. Give each host its own `id`, and set its values in `data-variable-values`:

```html
<div id="guest-name"
  data-composition-id="taam-lower-third"
  data-composition-src="compositions/taam-lower-third.html"
  data-variable-values='{"name":"Jane Doe","role":"Owner · Doe Plumbing","hold":4}'
  data-start="12" data-duration="4"
  data-track-index="2" data-track-kind="graphics"
  data-width="1920" data-height="1080" style="z-index:3"></div>
```

- **`hold` must match the host's `data-duration`.** The block times its exit from `hold`.
- **Transitions:** start the host 0.55 s before your cut. The frame is fully covered from 0.45 s to 0.75 s.
- **Captions:** run `npx hyperframes transcribe your-video.mp4 --model small.en`, then paste the words into `words` as `[{"text":"Hello","start":0.2,"end":0.5}, …]`. Times count from the captions host's `data-start`. Put the captions host on its own `data-track-kind="captions"` track. Captions and the lower third both sit at the bottom, so don't run them at the same time.
- **Stacking:** footage `z-index:1`, full-frame cards 2, overlays and stickers 3, captions 4, logo bug 5, progress bar 9, transitions 10.
- **Footage:** the grey `.plate` divs in the demo stand in for real clips. Swap each one for
  `<video id="clip-1" class="clip" src="assets/your-clip.mp4" data-start="4" data-duration="7" data-track-index="0" data-has-audio="true" playsinline style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;z-index:1"></video>`.

## Vertical (9:16)

Every block sizes from the frame (`cqmin`/`cqw` units), so it can mount in a 1080×1920 root. Set `placement: "vertical"` on the captions. Layouts are tuned for 16:9; look at a vertical render before you ship one.

## Sound

Sound effects live in `assets/sfx/` (Openverse, CC0 and CC BY). Each `<audio>` in the demo starts so the sound's peak lands one frame after the action it belongs to: pops on badges and cards, a slap on stickers and the word punch, whooshes on the wipes, a boing when the mascot lands, one impact on the stat payoff. **Credit the CC BY sounds listed in `assets/sfx/CREDITS.md` wherever a video using them is published.**

The music bed is `assets/bgm/groove.mp3` (HeyGen catalog, 105 BPM). It starts at 9.165 s into the file (`data-media-start`), where the full groove drops on a bar line, and fades out over the last 2 s. The final mix measures −15.9 LUFS with a −1.0 dBTP peak, inside the −16 to −14 LUFS social range; hits sit about 3–6 dB over the bed. `cartoon-boing-loud` and `air-whoosh-short-loud` are the downloaded files boosted by 18 dB, because the originals were recorded very quietly.

New music: sign in (`npx hyperframes auth login`, free), then run the audio engine with a `bgm.query` describing the feel and tempo. Find the track's drop and set `data-media-start` to it rather than starting on a quiet intro.

Rendering and the audio check need FFmpeg on PATH: `winget install --id Gyan.FFmpeg -e`. The demo renders to `renders/taam-kit-demo.mp4` with `npm run render -- --output renders/taam-kit-demo.mp4`.

# PART 3: Setting up on a new computer


**Docs, posters, pictures:** nothing to install. Install the fonts in `assets/fonts/` (double-click each .ttf → Install). For body text in Montserrat Regular, also install Montserrat from fonts.google.com/specimen/Montserrat (free).

**Video kit** (`taam-video-kit/`), install once:
1. Node.js LTS: `winget install OpenJS.NodeJS.LTS` (Mac: `brew install node`)
2. FFmpeg: `winget install --id Gyan.FFmpeg -e` (Mac: `brew install ffmpeg`)
3. Then in `taam-video-kit/`: `npm run dev` to preview, `npm run render` to make the MP4. The pinned HyperFrames version downloads itself on first run.
4. Optional, for AI captions: `npx hyperframes transcribe your-video.mp4 --model small.en`.

**Making new props/stickers** (optional):
1. Python 3 with Pillow and NumPy: `pip install pillow numpy`
2. Codex CLI, signed in (`npm i -g @openai/codex`, then `codex login`)
3. Video props: `cd taam-video-kit/art-src && ./gen.sh trophy "a chunky trophy cup"` then `python cutout.py props/trophy.png ../assets/props/trophy.webp`. On Windows run `gen.sh` from Git Bash.
4. Every prompt ends "no people, no hands, no faces, no silhouettes". Check every output.

**Sound credits:** CC BY sounds must be credited where a video is published. List: `taam-video-kit/assets/sfx/CREDITS.md`.
