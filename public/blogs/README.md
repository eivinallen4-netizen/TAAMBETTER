# Blog Thumbnails Directory

Add your blog thumbnail images here.

## How to Use

1. **Export your blog thumbnail** as PNG, JPG, or WebP
   - Recommended size: 1200×630 pixels
   - File size: Keep under 200KB for best performance

2. **Save it to this directory** with a descriptive name
   ```
   is-your-agency-holding-you-back.png
   how-to-scale-content.png
   etc.
   ```

3. **Reference it in `app/content/siteContent.json`**
   ```json
   "thumbnail": "/blogs/is-your-agency-holding-you-back.png"
   ```

## File Naming Guidelines

✅ **Good:**
- `is-your-agency-holding-you-back.png`
- `how-to-scale-content-creation.jpg`
- `agency-growth-strategy-2026.png`

❌ **Avoid:**
- `Blog Post 1.png` (spaces)
- `BLOG THUMBNAIL.png` (spaces, uppercase)
- `blog-thumbnail-final-final-FINAL.png` (too long)
- `Screen Shot 2026-08-03.png` (system defaults)

---

**Tip:** Keep file names lowercase and use hyphens instead of spaces or underscores.
