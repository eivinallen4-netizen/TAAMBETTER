# TAAM house rules

## Imagery
- Only the TAAM character style, on the slides and everywhere on the website: the black-and-white rubber-hose mascot (`/public/characters`) and props drawn in that same bold-outline, flat black-and-white style. No photographic, cinematic or 3D AI imagery. Generate new poses with Codex using the existing character PNGs as reference images.
- Never use Codex (or any AI image tool) to generate humans: no people, faces, bodies, crowds, silhouettes or hands.
- Allowed: the TAAM mascot character (`/public/characters`, `Mascot` component) and objects/items drawn in its style.
- Every image prompt ends with "no people, no hands, no faces, no silhouettes". Check each output before using it.

## Pricing
- TAAM never gives discounts. Never write "discount", "% off", "deal", "save", "sale price" or crossed-out prices.
- A smaller budget gets a smaller scope at the same rates, never a lower price. Bonuses are things we add, not money off.

## Personalized client slides (`/admin/contacts/[id]/deck`, `lib/deck.ts`, `app/admin/components/deck/`)
- Very good looking and straight to the point: one idea per slide, a big headline, at most 3–4 short lines. Cut anything a client would skim past.
- Use the sales/editorial design system: Montserrat all-caps headlines, strict orange `#F46325` / ink `#111111` alternation, white type, outline type for statements, big rounded image cards.
- Images follow the imagery rule above. No AI-generated people on any slide.
